## Português

Este repositório reúne meus estudos, exercícios, anotações e experimentos iniciais na área de Inteligência Artificial e Machine Learning.

Este material foi desenvolvido como preparação para minha Iniciação Científica (IC). Inicialmente, meu projeto de IC era voltado para **classificação de imagens**, e durante um período estudei os fundamentos necessários para desenvolver o projeto.

Nesse período, estudei:

- Python e exercícios de programação
- Fundamentos de Machine Learning
- Classificação de imagens
- Redes neurais e Deep Learning
- Pesos e bias
- Funções de ativação
- Funções de perda
- Softmax
- Otimização e Gradient Descent
- Treinamento e avaliação de modelos
- Transfer Learning
- Redes pré-treinadas, como ResNet, VGG e EfficientNet
- Experimentos com as bases MNIST, CIFAR-10 e Horses vs Humans
- Fundamentos de LLMs
- Transformers
- Tokenização e representação de textos

Após esse período de estudos, **troquei de projeto de Iniciação Científica**. O projeto inicial de classificação de imagens foi substituído por um novo projeto relacionado a **RAG (Retrieval-Augmented Generation) e LLM Wiki**.

Este repositório, portanto, registra a etapa inicial da minha formação em Inteligência Artificial e os estudos realizados durante a preparação para o primeiro projeto de IC.

## English

This repository contains my initial studies, exercises, notes and experiments in Artificial Intelligence and Machine Learning.

This material was developed as preparation for my Undergraduate Research Project (IC). Initially, my research project was focused on **image classification**, and during this period I studied the fundamentals required to develop the project.

During this period, I studied:

- Python and programming exercises
- Machine Learning fundamentals
- Image classification
- Neural networks and Deep Learning
- Weights and biases
- Activation functions
- Loss functions
- Softmax
- Optimization and Gradient Descent
- Model training and evaluation
- Transfer Learning
- Pre-trained models such as ResNet, VGG and EfficientNet
- Experiments with MNIST, CIFAR-10 and Horses vs Humans datasets
- LLM fundamentals
- Transformers
- Tokenization and text representation

After this period of study, **I changed my Undergraduate Research Project**. The initial image classification project was replaced by a new project related to **RAG (Retrieval-Augmented Generation) and LLM Wiki**.

Therefore, this repository documents the initial stage of my studies in Artificial Intelligence and the work carried out while preparing for my first research project.
